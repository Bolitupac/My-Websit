What PR‑AI can do

🔍
Pull Request Audit
Analyzes open or merged PRs for merge readiness, correctness, and risk — with line-level inline comments pinned to exact file paths.
🌿
Branch Audit
Reviews branch diffs before integration — flags missing checks, integration risk against the base branch, and pre-merge blockers.
📜
Commit Audit
Historical post-change review focused on regression risk, hidden side effects, rollback concerns, and follow-up fixes needed.
🗂️
Mermaid Impact Diagrams
Generates Sequence, Flowchart, or Class diagrams automatically to map the impact of every change in a human-readable visual.
💬
AI Chat on Diff Context
After any audit, continue the conversation — ask follow-up questions about the diff, security tradeoffs, or refactoring ideas with full context retained.
🔗
GitHub / GitLab Import
Import directly from GitHub or GitLab — paste a repo URL, pick a PR or branch, and PR-AI fetches the diff and metadata automatically.
🎙️
Voice Input (Whisper)
Speak your audit questions — integrated OpenAI Whisper transcription lets you describe what you want reviewed hands-free.
📋
Inline Code Comments
Up to 8 structured inline comment objects per audit — each pinned to an exact file path, line number, and diff side (LEFT or RIGHT).
🤖
Multi-Model Support
Switch between OpenAI models (gpt-4o, gpt-4o-mini, etc.) per audit — balance speed vs. depth depending on the PR size.
